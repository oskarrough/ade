# Fonts

Served locally so opening the client contacts no font CDN. Inter sets the text and the interface, iA Writer Quattro S sets code.

## Inter

The variable webfonts, unmodified, from [rsms.me/inter](https://rsms.me/inter/). The [SIL Open Font License](LICENSE-Inter.txt) covers both files.

## iA Writer Quattro S

Unmodified webfonts from [iA Fonts, commit c658867](https://github.com/iaolo/iA-Fonts/tree/c6588670c71e9ac628acc27b72cde4bf12726b7f/iA%20Writer%20Quattro/Webfonts). The [SIL Open Font License](LICENSE.md) covers all four files.
