# tldraw's agent starter kit, the actions' schema

From [tldraw/agent-template](https://github.com/tldraw/agent-template) at `1e7c07eeb5c3e6a561328df3589b2f0c0e2ca556`, MIT (LICENSE.md here). `actions.schema.json` is the JSON schema of the actions the server offers agents with `canvas_act`: create, update, delete, move and label, the ones that need no layout. Don't edit it here: refresh it with `scripts/vendor-canvas-agent.js`, which says how, and update the commit above.
